## SWAN是什么？

SWAN的全称为Simulating WAves Nearshore，也即“近岸波浪模拟模式”。为荷兰代尔夫特理工大学（简称Delft）土木工程系开发的第三代海浪模型。该项目曾经受到美国海军研究办公室（简称ONR）资助，目前部分资金来自荷兰水务局。

SWAN的官网可通过检索关键词“SWAN Delft”查询到：
Delft土木系官网上对SWAN的介绍
[https://www.tudelft.nl/en/ceg/about-faculty/departments/hydraulic-engineering/sections/environmental-fluid-mechanics/research/swan)](https://www.tudelft.nl/en/ceg/about-faculty/departments/hydraulic-engineering/sections/environmental-fluid-mechanics/research/swan)
SWAN自身的官网
[https://swanmodel.sourceforge.io](https://swanmodel.sourceforge.io)

SWAN也托管于Gitlab [citg / wavemodels / SWAN · GitLab](https://gitlab.tudelft.nl/citg/wavemodels/swan)，其包含了CMake文件

## 下载安装

截至2026年5月25日，最新版为41.51

可直接下载源代码压缩包，代码为F90格式，需要具备Fortran 90编译器。构建的时候，要查询install.README，构建可参考Implementation Manual手册

也可使用预先编译的二进制版本

也可以使用docker进行容器化部署，该方法易于移植


### 安装Fortran
此处省略，可使用开源的GFortran。大型计算可使用intel Fortran。其它编译器可参考Implementation Manual的3.2.1
[Installing GFortran — Fortran Programming Language](https://fortran-lang.org/learn/os_setup/install_gfortran/)

### 构建
此处采用经典构建方法，参照Implementation Manual的3.2.2或Makefile文件内部
下载官网download页面源代码，解压并cd进入文件夹。输入

```
make config
```
以自动生成macro.inc文件，该文件包含与机器相关的宏的包含文件

接下来选择运行模式
1. 串行计算（serial runs）：单核处理器顺序计算，多用于简单调试
2. 并行计算、共享内存：单台多核心计算机
3. 并行计算、分布式内存：计算机集群

串行运行的命令为
```
make ser
```

并行计算(共享内存)的命令为
```
make omp
```
并行计算（分布内存）的命令为
```
make mpi
```
